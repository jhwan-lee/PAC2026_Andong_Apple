## 2. 핵심 알고리즘 특징

### 2.1 조명 불변성 착색도 분석 (`apple_quality_detector.py`)
- **CIE-Lab & HSV 하이브리드 판정**: 공장의 어두운 조명과 그림자 노이즈를 극복하기 위해 명도($L^*$)를 분리하고, 적색 파장($a^*$ 채널 및 Hue 0~15°, 165~180°) 기반으로 사과 유효 착색 비율을 계산합니다.
- **반사광(Specular Highlight) 필터링**: 사과 표면의 반사광을 결점이나 색상으로 오인하지 않도록 자동 마스킹합니다.
- **국립농산물품질관리원 사과 표준규격 준용**:
  - 기본 2등급: **상**(밝은 색, 착색률 60% 이상) / **중**(어두운 색, 착색률 미달)
  - 확장 3등급: **특**(착색 70% 이상, 무결점) / **상**(착색 50~70%) / **보통**(착색 30~50%) / **리젝트**(결점 8% 초과 또는 착색 30% 미만)
- **다면 검사(Multi-view) 지원**: 로봇이 사과를 집고 회전시키며 촬영한 다중 프레임(전/측/후면)을 입력받아 최저 착색면 가중치를 반영한 종합 품질을 산출합니다.

### 2.2 3D 로봇 파지 좌표 변환 (`apple_locator.py`)
- 트레이 위 임의 위치에 있는 사과 5개의 중심점 픽셀 $(u, v)$ 및 반지름 검출
- Hand-Eye 캘리브레이션 행렬을 통해 WeGo PIPER 로봇 베이스 기준 $(X, Y, Z\text{ mm})$ 좌표로 정밀 변환
- 이동 동선 최소화(Greedy/TSP)를 통한 픽업 순서 자동 정렬 (사이클 타임 단축)

## 3. 실행 및 테스트 방법

### 가상환경 활성화 및 패키지 설치
```bash
# 가상환경 생성 (최초 1회)
python -m venv .venv

# 의존성 설치
pip install -r requirements.txt
```

### 통합 시뮬레이션 테스트 실행
```bash
python test_quality_pipeline.py
```
- 실행 시 트레이 위 5개 사과 가상 장면 생성 → 위치 추정 → 착색도 및 품질 등급 판정 → 다면 검사 시뮬레이션 → `quality_inspection_result.png` 저장까지 원클릭으로 검증됩니다.

## 4. 5인 팀 R&R (역할 분담)

1. **팀원 1 (팀장)**: ROS2 / Python 상태 머신(State Machine) 시퀀스 총괄, 예외 처리
2. **팀원 2 (비전 좌표)**: 카메라 세팅, Hand-Eye 캘리브레이션, 사과 3D 위치 추정 정밀화
3. **팀원 3 (AI 품질 판정)**: 착색도/결점 알고리즘 튜닝, 다면 검사 이미지 합성 로직
4. **팀원 4 (로봇 제어)**: WeGo PIPER 6축 기구학(IK/FK), 부드러운 픽앤플레이스 동선 최적화
5. **팀원 5 (하드웨어/안전성)**: 사과 멍 방지 소프트 그리퍼 패드 3D 프린팅, 파지 토크/전류 정량 데이터 리포트 도출
